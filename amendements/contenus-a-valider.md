# Contenus du site vitrine — document à valider

> Document de travail préparé à partir des fichiers `amendements/`. Les textes sont nettoyés (sections séparées, artefacts de génération supprimés) mais **rien n'a été publié** : les données manquantes et les affirmations à vérifier sont signalées.

## Légende

| Balise | Signification |
| --- | --- |
| `[À COMPLÉTER]` | Information à fournir par SIBEA (chiffre, année, nom, signature). |
| `[À VALIDER]` | Affirmation, certification ou chiffre à confirmer avant publication. |
| `[Proposition]` | Reformulation suggérée (SEO / ton / cohérence) — la version d'origine reste la référence. |

## Recommandations générales avant intégration

1. **Choisir un vocabulaire unique** : le site dit « secteurs d'activité » ; ces textes alternent « pôles », « métiers », « branches ». Recommandation : « secteur » dans la navigation, « pôle » possible dans le discours corporate.
2. **Valider tous les chiffres et certifications** : les mentions HSE, ISO, HACCP, « zéro litige », « 0 accident grave », « 100 % » sont des engagements vérifiables.
3. **Renforcer les H1 pour le SEO** : les titres proposés sont évocateurs mais sans mots-clés. Chaque H1 proposé ci-dessous est accompagné d'une variante `[Proposition]` avec l'activité et la zone (Abidjan / Côte d'Ivoire).
4. **Pas d'emojis dans les titres du site** : ils sont retirés ici.
5. **Où intégrer quoi** : les textes d'accueil et du groupe peuvent être saisis via l'administration existante (Paramètres, Pages éditoriales). Les pages secteur nécessitent l'étape 2 (pages dédiées) et devront attendre la validation des contenus.

# 4. Pages secteur

## 4.1 Canevas commun

Chaque page secteur suit la même structure :

1. **Hero** : image immersive + H1 + bouton d'action.
2. **Introduction & chiffres clés** : 3 à 4 lignes de positionnement + 3 ou 4 compteurs.
3. **Nos domaines d'expertise** : 4 cartes (sous-activité, icône, description de 2 lignes).
4. **Nos réalisations majeures** : 3 projets du secteur (nom, lieu/client, lien vers l'étude de cas).
5. **Engagements & certifications** : sécurité, matériaux durables, empreinte carbone, labels.
6. **Appel à l'action final** : bloc contrasté + bouton vers le contact.
